# Weltpolice Belege

Kleine Web-App (PWA) zum Erfassen von Arztbelegen und zum Erstellen des
„Leistungsauftrags zur Barmenia-Weltpolice“ als PDF.

- Belege fotografieren oder als PDF hinzufügen, Diagnose und Anmerkung frei oder aus Vorschlägen wählen
- Warnung bei doppelt erfassten Belegen
- Export als PDF und/oder Word (.docx), wahlweise klein für den E-Mail-Versand
- Warnung bei doppelt erfassten Belegen
- Export als PDF und/oder Word (.docx), wahlweise klein für den E-Mail-Versand
- Automatische Beleg-Nummerierung (z. B. 7a-b) mit Stempel auf jedem Beleg
- PDF mit Tabelle, Summe, Konto, Unterschrift und allen Belegen, teilbar per E-Mail
- **Alle Daten bleiben lokal auf dem Gerät** (IndexedDB). Dieses Repository enthält nur den App-Code.

Installation auf dem iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
